## 2. Random Slopes by Cuisine (Strict Effects)
- Create a new script: `analyses/02_acat_multilevel/run_models_rs_strict.R`.
- Model Formula: `rating_ord ~ 1 + social_c + age.f + race.f + gend.f + educ.f + inc.f + (1 | respondent_id) + (1 + social_c | cuisine)`
- This model tests if the effect of social conservatism varies significantly between different cuisines.
- Computational strategy: Use 2 cores, 6000 iterations (similar to Model 2 limits).
- Comparison: Calculate WAIC (subsampled to 1000 draws to avoid OOM) and compare it against the strict additive model (`fit_strict_acat.rds`).

## 3. Social vs. Economic Conservatism (Category-Specific)
- Create a new script: `analyses/02_acat_multilevel/run_models_econ_soc_cs.R`.
- Data Prep: Add mean-centering for the `economic` ideology variable (`economic_c`), mirroring `social_c`.
- Model Formula: `rating_ord ~ 1 + cs(social_c) + cs(economic_c) + age.f + race.f + gend.f + educ.f + inc.f + (1 | respondent_id) + (1 | cuisine)`
- This model will allow us to see if cultural/social conservatism or economic conservatism is the primary driver of taste, while allowing both to have non-linear effects across the rating thresholds.
- Comparison: Compare via WAIC against the current category-specific model (`fit_cs_acat.rds`).

## 4. Posterior Predictive Checks (PPC)
- Create a new script: `analyses/02_acat_multilevel/run_ppc.R`.
- Load the winning `fit_cs_acat.rds` model.
- Generate a `pp_check(fit, type = "bars", ndraws = 100)` to visualize how well the model predicts the observed ordinal distributions.
- Save the plot to `Plots/02_acat_multilevel/ppc_bars.png`.
- Integrate the plot and an interpretation into the `.qmd` report.

## 5. Interaction: Ideology × Education
- Create a new script: `analyses/02_acat_multilevel/run_models_interaction_strict.R`.
- Model Formula: `rating_ord ~ 1 + social_c * educ.f + age.f + race.f + gend.f + inc.f + (1 | respondent_id) + (1 | cuisine)`
- We will use strict effects for this interaction to keep it computationally tractable and avoid the massive parameter explosion of interacting category-specific terms.
- Comparison: Compare via WAIC against the strict additive model (`fit_strict_acat.rds`).
