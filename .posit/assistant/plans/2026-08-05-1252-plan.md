# Plan: Musical Genre ACAT Multilevel Modeling

## Objective
Replicate the successful Bayesian Adjacent Category (ACAT) multilevel pipeline used for cuisine authenticity, but apply it to the 20 musical genre ratings (1 to 7 scales) from the `qualtrics-original.dta` dataset.

## Step-by-Step Implementation

1. **Update Qualtrics Data Prep (`data/recode.qualtrics.R`)**
   - Add political ideology variables: The survey contains `social` and `econ` variables (1-7 scales). I will rename `econ` to `economic` to match the previous pipeline.
   - Add centralization: Generate `social_c` and `economic_c` (centered and scaled) in the prep function alongside `age_c`, `educ_c`, and `income_c`.
   - Map the cryptic column names (`like_music_genres_21` through `40`) to their clean genre names (e.g., `swing`, `country`, `rap`, `classical`) so the model outputs are readable.

2. **Create New Analysis Directory**
   - Create `analyses/music-acat-multilevel/` to isolate the music analysis from the cuisine analysis.

3. **Port and Adapt the Multilevel Bayesian Models**
   - We will create 5 `.R` scripts utilizing `brms` and `cmdstanr`, matching the architecture that succeeded for food:
     - `music_hier_1_baseline.R`: Baseline model with global fixed effects and random intercepts for `respondent_id` and `genre`.
     - `music_hier_2_relaxed.R`: Relaxes the proportional odds assumption by using category-specific `cs()` effects for ideology and capital.
     - `music_hier_3_rs.R`: Adds Random Slopes so that the effects of demographics vary by musical genre.
     - `music_hier_4_var.R`: The **Distributional Variance model** predicting the `disc` parameter (consensus/variance) with random intercepts.
     - `music_hier_5_var_rs.R`: The ultimate **Variance + Random Slopes** model (which fit best for cuisine).
   
4. **Create a Job Queue**
   - Create `run_music_hierarchy_queue.sh` in the root folder.
   - This bash script will run models 1 through 5 in sequence using `nohup`, piping outputs to `logs/music_hier_*.log` and caching the `.rds` objects in `cache/` (while respecting the `cores=4`, `threads=3` RAM management approach we established).

**Note:** Once these are queued and compiled, a future session can extract the model fits to generate the 2D Variance/Consensus mappings and Category-Specific plots for music!
