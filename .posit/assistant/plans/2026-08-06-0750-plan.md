# Plan: Unified Pipeline for Music, TV, and Movie ACAT Reports

To avoid duplicating dozens of plotting scripts and Quarto files, we will build a DRY (Don't Repeat Yourself) automated pipeline using a universal R plotting function and a **Parameterized Quarto Document**. 

## Phase 1: Universal Plotting Script (`scripts/generate_domain_plots.R`)
Instead of separate scripts for every plot and domain, we will write a single R script containing a master function: `generate_domain(domain_prefix, domain_name)`. 

This function will:
1. Dynamically load the `.rds` model files from `cache/` (Models 1 through 6) based on the `domain_prefix` (e.g., `music`, `tv`, `mov`).
2. Extract the posterior draws using `tidybayes`.
3. Generate the full suite of plots with a consistent style matching the Cuisine report:
   - WAIC Model Fit Comparison
   - Global Demographic Fixed Effects (Location)
   - Baseline Genre Effects (Random Intercepts)
   - 2D Consensus Map (Location vs Variance)
   - Demographic Effects on Consensus (Variance)
   - Random Slopes for Ideology & Cultural Capital (Location & Variance)
   - Category-Specific (CS) thresholds (Midpoint & Raw thresholds) for Ideology and Cultural Capital.
4. Save the cleanly styled `.png` files into `Plots/<domain>-acat-multilevel/`.

We will simply call this function three times at the bottom of the script:
```r
generate_domain("music", "Musical Taste")
generate_domain("tv", "Television Taste")
generate_domain("mov", "Movie Taste")
```

## Phase 2: Parameterized Quarto Template (`scripts/analysis_template.qmd`)
Instead of maintaining three separate `.qmd` files, we will create one master Quarto template. It will use Quarto YAML `params` to dynamically alter the text and image paths.

*   `params$domain` will dictate which folder of plots to load.
*   `params$title` will dynamically update the document title (e.g., "Television Taste and Preference").
*   The text will dynamically reference the "1 (Strongly Dislike) to 7 (Strongly Like)" scale.

## Phase 3: Master Build Script (`build_all_reports.sh`)
We will create a single executable bash script to trigger the entire pipeline once the models finish computing:
```bash
#!/bin/bash
# 1. Generate all plots
Rscript scripts/generate_domain_plots.R

# 2. Render reports
quarto render scripts/analysis_template.qmd -P domain:"music" -P title:"Musical Taste" --output analysis.html
mv scripts/analysis.html analyses/music-acat-multilevel/analysis.html

quarto render scripts/analysis_template.qmd -P domain:"tv" -P title:"Television Taste" --output analysis.html
mv scripts/analysis.html analyses/tv-acat-multilevel/analysis.html

quarto render scripts/analysis_template.qmd -P domain:"mov" -P title:"Movie Taste" --output analysis.html
mv scripts/analysis.html analyses/movie-acat-multilevel/analysis.html
```

## Outcome
When the `.rds` files are finished writing, you will only need to run `./build_all_reports.sh` to automatically extract the posteriors, generate universally styled plots, and produce three identical, perfectly formatted HTML reports in their respective directories.
